# my-first-ml-project
# 我的第一个机器学习项目：糖尿病进展预测

## 📌 项目简介
这是一个基于 Scikit-learn 的线性回归小项目，用于预测糖尿病患者的疾病进展。

## 🛠️ 使用技术
* **语言**：Python
* **工具**：Jupyter Notebook / PyCharm
* **核心库**：Pandas, Scikit-learn, Matplotlib

## 📊 数据来源
使用了 Scikit-learn 内置的 `diabetes` 数据集（包含442名患者的数据）。

## 🚀 实现流程
1. 加载并了解数据。
2. 提取 BMI（体重指数）作为特征进行建模。
3. 将数据划分为训练集（80%）和测试集（20%）。
4. 使用线性回归（Linear Regression）训练模型。
5. 评估模型均方误差（MSE），并画出真实值与预测值的对比图。
